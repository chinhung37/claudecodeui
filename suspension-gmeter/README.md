# 避震 G 值計（手機 PWA）

用手機本身的加速度計＋陀螺儀，判讀前／後／左／右避震偏軟或偏硬，並可記錄、回放、匯出。
Android（Chrome）與 iPhone（Safari）都可用，「加入主畫面」後就像一般 App，開過一次後離線也能用。

## 量什麼

| 位置 | 指標 | 怎麼來 | 越大代表 |
|---|---|---|---|
| 前 | 點頭 deg/g | 穩定煞車時，車頭下沉角度 ÷ 減速 G | 越軟 |
| 後 | 蹲尾 deg/g | 穩定加速時，車尾下沉角度 ÷ 加速 G | 越軟 |
| 左 | 右彎側傾 deg/g | 右彎（左側為外側）時側傾角 ÷ 側向 G | 越軟 |
| 右 | 左彎側傾 deg/g | 左彎（右側為外側）時側傾角 ÷ 側向 G | 越軟 |
| 四輪 | 路感比 | 該輪位置垂直加速度 4–15 Hz RMS ÷ 0.5–3 Hz RMS | 越硬 |

- 角度：陀螺儀積分；車子回到無加減速、無側向 G 時自動歸零，抵消漂移。
- 四輪垂直加速度：用手機位置的垂直加速度，加上俯仰/側傾角加速度乘上「手機到各輪的距離」推算（剛體假設），所以要在設定填軸距、輪距、手機位置。
- 縱/橫向 G 會扣掉車身傾斜造成的重力分量。

## 限制（未驗證的部分）

- 判讀門檻預設值是經驗值，**未驗證**。最可靠的用法是「同一路線、調整前後各錄一段」，把調整前設為基準，開「與基準比較」。
- 各品牌手機的 `rotationRate` 軸定義是否都符合 W3C 規範：**未驗證**。紀錄頁會顯示「陀螺儀軸檢查」（偏航角速度與側向 G 的相關係數）協助判斷，設定頁可切換軸對應與各方向反轉。
- 點頭/蹲尾同時受懸吊幾何（anti-dive/anti-squat）、煞車配比、驅動方式影響。
- 坡道與路面起伏會混入姿態；手機支架若會晃，高頻（路感比）會失真。
- 瀏覽器在螢幕關閉或切到背景時會停止送感測資料。記錄中請保持畫面開著（App 有要求螢幕常亮）。

## 部署到手機

感測器 API 只在 HTTPS 下可用。

**GitHub Pages（建議）**
1. Repo → Settings → Pages → Source 選 **GitHub Actions**。
2. Actions 分頁 → 「Deploy suspension-gmeter to Pages」→ Run workflow。
3. 手機開啟產生的網址 → 分享選單 / 選單 →「加入主畫面」。

**Windows 11 本機開發**
- 電腦瀏覽器可直接 `npx serve suspension-gmeter` 看介面（`localhost` 視為安全來源，但電腦通常沒有動作感測器）。
- 要用手機連電腦測試，需要 HTTPS 隧道（例如 `cloudflared tunnel --url http://localhost:3000`），用它給的 https 網址開。

## 使用流程

1. 設定：軸距、前後輪距、手機到前軸距離、手機偏離中心線距離（mm）。
2. 啟動感測器（iPhone 會跳權限，要允許）。
3. 校正：靜止 3 秒 → 選車頭方向（螢幕朝駕駛／平放頂端朝前／自動：直線起步加速）。
4. 檢查方向：煞車時 G 球往上、左彎往右；壓車頭俯仰為 +、壓右側側傾為 +。不對就到設定勾反向。
5. 記錄：開一段包含煞車、加速、左右彎、一般路面的路線。
6. 紀錄頁：回放（可拖曳時間軸、0.5–4 倍速）、設為基準、匯出 CSV、備份/匯入 JSON。
   回放會用「目前的設定」重新計算，所以事後改幾何或反向設定也能套用到舊紀錄。

## 檔案

- `analysis.js`：分析核心（座標轉換、濾波、deg/g 回歸、四輪投影），瀏覽器與 Node 共用，測試在 `test/suspension-analysis.test.js`。
- `demo.js`：模擬行車示範資料（第一次打開、或按「看示範」時使用；數值是虛構的）。
- `app.js`：介面、感測器、校正、記錄（IndexedDB）、回放、匯出。
- `sw.js`、`manifest.webmanifest`：PWA 離線與安裝。
- `build-single.js`：合成單一 HTML 檔：`node suspension-gmeter/build-single.js 輸出.html`。

## 單檔版（Claude Artifact）的限制

嵌在 Claude 檢視器裡時，動作感測器會被封鎖，所以單檔版只能：看模擬示範、匯入 PWA 版的備份檔（.json）回放分析、匯出 CSV。
實際上車量測請用 HTTPS 網址直接開啟的 PWA 版。
