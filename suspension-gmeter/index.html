使用步驟

  1. 手機用硬式支架固定在車上（軟爛支架會自己共振，路感比會失真）。
  2. 到「設定」填軸距、輪距、手機位置。
  3. 按「啟動感測器」（iPhone 會跳出動作感應權限，要允許；接著會問位置權限，用來取得 GPS 時速，也建議允許）。
  4. 車停好、引擎可以發動，按「校正」，第一步保持靜止 3 秒。
  5. 第二步選前方：手機螢幕朝向駕駛就選「螢幕朝駕駛」；否則選「自動」，然後直線起步加速。
  6. 校正後檢查：煞車時 G 球往上、左轉時 G 球往右；壓車頭俯仰為 +、壓右側側傾為 +。不對就到設定勾反向。
  7. 按「開始記錄」，開一段有煞車、加速、左右彎、一般路面的路線，再停止。

數值意義

  • 前 = 點頭 deg/g：煞車時每 1g 車頭下沉幾度。越大越軟。
  • 後 = 蹲尾 deg/g：加速時每 1g 車尾下沉幾度。越大越軟。
  • 左 = 右彎側傾 deg/g：右彎時左側是外側、被壓縮。越大越軟。
  • 右 = 左彎側傾 deg/g：左彎時右側被壓縮。
  • 四輪路感比 = 路面震動（4–15 Hz，手機位置實測）÷ 該輪位置的車身擺動（0.5–3 Hz）。車身擺動越少、比值越大 = 越硬。沒設基準時，顏色是跟這次四輪平均比較，看哪一角相對硬或軟。
  • 可靠度：點頭、蹲尾、側傾要「角度跟 G 值同步變化」才算數（R² ≥ 0.5）。溫和駕駛時路面起伏比車身傾斜還大，會顯示「不可靠」；請在平路做幾次明確的煞車（約 0.3g 以上，從 40 km/h 減速到停）與加速。
  • 時速分段：車速越快，路感比通常越大。有 GPS 時速時，路感比會另外分成 0–30、30–60、60 以上 km/h 三段；與基準比較也只比同一時速段（標示「同時速段」）。沒有 GPS 的紀錄只能整段比（標示「未分時速」）。

限制（請一定要看）

  • 一支手機只有一個量測點；四輪的垂直加速度是用陀螺儀的俯仰/側傾角加速度做剛體推算，不是四個真的感測器。
  • 點頭/蹲尾也受懸吊幾何（anti-dive / anti-squat）、煞車配比、驅動方式影響，不只是彈簧阻尼。
  • 手機在支架上的高頻晃動比車身擺動大很多，所以四輪只推算低頻的車身擺動；高頻路面震動四輪共用手機位置的實測值。
  • 坡道、路面起伏會混進姿態；請在平路比較。
  • 判讀門檻的預設值是經驗值，未驗證。最可靠的用法是：調整前錄一段 → 設為基準 → 調整後同一路線再錄 → 開「與基準比較」。
  • 不同手機的陀螺儀軸定義可能不同（未驗證每款手機）。紀錄詳情裡的「陀螺儀軸檢查」會告訴你哪個對應比較合理。
  • 螢幕關掉或切到別的 App 時，瀏覽器會停止送感測資料；記錄中請保持畫面開著。
  • GPS 大約每秒更新一次，隧道、地下道、高樓之間會沒有時速；超過 3 秒沒更新就當作不知道，那段不列入分段統計。
